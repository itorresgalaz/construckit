# Documentación

La entrega exige un README con: cómo arrancar, decisiones tomadas, exclusiones justificadas y las respuestas de la Parte 2 de `docs/Prueba.md` (máximo 10 líneas cada una).

Actualizar README cuando:

Se agreguen endpoints.

Se creen modelos.

Se agreguen variables de entorno.

Se tome una decisión ambigua (ver `context/business_rules.md`).

Actualizar la colección Postman o los ejemplos de llamadas.

`docs/` no se versiona (`.gitignore`): nada que deba llegar al evaluador puede vivir solo ahí.
