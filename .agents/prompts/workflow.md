# Workflow obligatorio

Antes de escribir una sola línea de código:

1. Indexar el proyecto con codebase-memory-mcp.
2. Identificar todos los archivos afectados.
3. Mostrar el plan de implementación.
4. Esperar confirmación si el cambio es estructural.
5. Implementar con la estructura de `architecture.md` (MVC + un servicio), sin sobreingeniería.
6. Actualizar pruebas, documentación y migraciones si corresponde.
7. Hacer commits incrementales cuando el usuario lo pida.
8. Entregar un resumen final con:
   - Archivos modificados.
   - Riesgos detectados.
   - Pasos para validar el cambio.
   - Mejoras futuras.
